# 쇼츠템 브레인스토밍 결과

날짜: 2026-06-24

---

## 앱 정체성

**핵심 정의:** 유튜브에서 본 추천템을 빠르게 저장하고, 예산 범위 안에서 관리하는 앱

- **1순위 기능**: 쇼핑 위시리스트 — 유튜브 쇼츠 보다가 바로 상품 저장
- **2순위 기능**: 예산 관리 — 카테고리별 지출 한도 관리
- **주요 사용 맥락**: 유튜브 시청 중 즉시 캡처 → 구매 고민 시 목록 확인

---

## 결정된 방향

### A. 데이터 영속성 — Supabase

- **방식**: Supabase 익명 인증 (anonymous auth)
- **이유**: 로그인 마찰 없이 기기 간 데이터 유지
- **추후 확장**: 소셜 로그인(구글 등) 추가로 계정 연동 가능하게

### B. 상품 상세 & 찜 목록

- **상품 상세 페이지**: 상품명, 가격, 판매처, 출처 영상, 메모 표시
- **찜 목록**: 홈 화면 미리보기 + 전체 목록 화면 (현재 구현됨, 강화 필요)
- **구매 완료 처리**: 추후 논의 (status: 'purchased' 타입은 준비됨)

### C. 분석 품질 개선 — Gemini 프롬프트 튜닝

- **이미지**: 네이버 쇼핑 API 미추가, 복잡도 대비 효과 낮음으로 보류
- **가격 정확도**: Gemini 프롬프트 개선으로 해결

## 서버 가격 로직 개선 (미완료 — 다음 세션에서 이어서)

현재 발견된 문제점:

| # | 문제 | 위치 | 개선 방향 |
|---|------|------|-----------|
| 1 | description 2000자 잘림 | `analyzeWithGemini` | 4000자로 확대 |
| 2 | 자막 API 비신뢰 (쇼츠에서 거의 빈값) | `fetchCaptions` | 실패 시 fallback 처리 명확화 |
| 3 | `known` vs `estimated` 구분 모호 | Gemini 프롬프트 | 정의 구체화 |
| 4 | 댓글 가격 정규식 누락 패턴 | `fetchCommentPrices` | `1.5만원`, `15000원` 등 추가 |
| 5 | 가격 우선순위 불명확 | Gemini 프롬프트 | 우선순위 명시 (설명/자막 > 댓글 > 시세 > 추정) |
